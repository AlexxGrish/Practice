Пользователи и роли

Главная / Администрирование

Раздел доступен только пользователям с ролью Администратор.

Управление пользователями

  1. Откройте «Администрирование» → «Пользователи».
  2. Нажмите «Добавить», чтобы создать учётную запись.
  3. Укажите логин, ФИО, роль и пароль.
  4. Для изменения данных выделите пользователя и нажмите «Изменить».

Роли

РольПрава
АдминистраторПолный доступ, включая пользователей
РуководительВсе расчёты, справочники и отчёты
МенеджерРасчёты и отчёты

Смена собственного пароля

Меню «Администрирование» → «Изменить свою учётную запись» позволяет сменить пароль. Новый пароль должен быть непустым.

Не передавайте пароль администратора другим сотрудникам. При увольнении сотрудника учётную запись следует заблокировать или удалить.
