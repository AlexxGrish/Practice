Рабочее окно и навигация

Главная / Интерфейс

Главное окно состоит из верхнего меню, боковой панели, рабочей области и статусной строки.

Верхнее меню

  • Пользователи — смена пользователя и выход из системы.
  • Вычисления — переход к расчётным модулям, товарам и отчётам.
  • Таблицы справочники — открытие справочников и их разделов.
  • Генерация отчётов — быстрый переход к нужному отчёту.
  • Администрирование — доступно только администратору.
  • О программе — сведения о версии и разработчике.

Боковая панель

Содержит те же основные разделы, что и меню, и позволяет переключаться между модулями одним нажатием. Активный раздел выделяется цветом.

Рабочая область

В верхней части модуля расположены параметры расчёта, ниже — таблицы, чекбоксы включения строк и кнопки экспорта. Результаты выделены цветом, итоговые значения находятся под таблицей.

Статусная строка

Показывает текущего пользователя, состояние подключения к базе данных и системное время.
