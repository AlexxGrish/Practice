## Справка

В приложении есть справка: кнопка «? Справка» в верхнем доке или клавиша F1. Открывается `Help\PracriceHelp.chm` (копируется во временную папку с коротким путём, чтобы HTML Help корректно отображал страницы); HTML-версия `Help\PracriceHelp.html` оставлена как резервная. Исходные HTML-страницы, CSS и проект сборки находятся в папке `Help`.
