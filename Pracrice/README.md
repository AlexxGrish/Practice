# ООО «РОСПИВ» — информационная система

Учебный WPF-проект (`.NET 9`, WPF, Entity Framework Core, Pomelo MySQL, BCrypt) для компании
ООО «РОСПИВ». Оформление выполнено в фирменной зелёно-золотой гамме, используется логотип
компании и единая иконка приложения.

## Быстрый запуск

1. Запустите MySQL/MariaDB (в проекте проверено на OpenServer, MySQL 5.7, порт `3306`).
2. Соберите проект:
   ```powershell
   dotnet build Pracrice.csproj
   ```
3. Запустите `bin\Debug\net9.0-windows\Pracrice.exe`.
4. При первом запуске приложение само создаст базу `RosPiv`, таблицы и учётную запись
   администратора:
   - логин: `admin`
   - пароль: `admin123`

   После входа пароль следует сменить в разделе «Администрирование» → «Изменить свою учётную запись».

## Настройки подключения

Рядом с `Pracrice.exe` находится файл `config.ini`:

```ini
[Database]
Host = 127.0.0.1
Port = 3306
User = root
Password =
DB = RosPiv
```

Приложение:
- проверяет наличие и доступность файла;
- создаёт файл с настройками по умолчанию, если он отсутствует;
- проверяет соединение с сервером и создаёт базу при необходимости;
- выводит понятное сообщение и завершает работу, если подключение невозможно.

Файл копируется в каталог сборки автоматически. Если изменить `config.ini` в каталоге
`bin\Debug\net9.0-windows`, при следующей сборке он не будет перезаписан, пока исходный
файл старше.

## Роли

| Роль в БД | Отображаемое имя | Возможности |
|---|---|---|
| `administrator` | Администратор | Все разделы, управление пользователями |
| `director` | Руководитель | Планы, отчёты, справочники, товары |
| `manager` | Менеджер | Товары, справочники, отчёты, планы |

Пароли хранятся только в виде хеша BCrypt. Для совместимости с ранее сохранёнными
SHA-256-хешами предусмотрена проверка старого формата с последующим перехешированием.

## Реализованные разделы

- Вход по логину и паролю.
- Администрирование: добавление, редактирование и удаление пользователей в отдельном окне.
  Свою учётную запись удалить нельзя; нельзя удалить последнего администратора.
- Товары: каталог, карточка товара, изображение, артикул, цена.
- Справочники: ресурсы, склады, магазины, рецептуры, расстояния, складские остатки,
  инвестиционные компании и ставки. Добавление и редактирование — только в отдельных окнах.
- Отчёты в HTML: товары, складские остатки, рецептуры, инвестиционные ставки, пользователи,
  а также отчёт по любому справочнику. HTML-отчёт можно распечатать средствами браузера (Ctrl+P).
- Главное меню и боковая панель навигации, контекстные меню таблиц.
- Строка состояния: текущая дата, время (обновляется каждую секунду), ФИО и роль пользователя.
- Расчётные модули: план выпуска, план перевозок (закрытая и открытая задача), обновление
  оборудования, планирование касс и распределение инвестиций.
- В таблицах расчётных модулей есть чекбоксы включения данных в расчёт.
- Кнопки «Экспорт» формируют HTML-отчёт по результатам расчёта.
- Расчётные модули: план выпуска, план перевозок (закрытая и открытая задача), обновление
  оборудования, планирование касс и распределение инвестиций.
- В таблицах расчётных модулей есть чекбоксы включения товаров, складов, магазинов, оборудования
  и проектов в расчёт.
- Кнопки «Экспорт» формируют HTML-отчёт по результатам расчёта и открывают его в браузере.

## Изображения товаров

- Изображения хранятся в папке `images` рядом с исполняемым файлом.
- В базе данных хранится относительная ссылка вида `images/имя_файла.png`.
- В карточке товара можно выбрать изображение (PNG, JPG, JPEG, BMP, GIF), заменить или удалить его.
- При удалении товара его изображение также удаляется.
- Если изображение не задано, показывается фирменная заглушка.

## База данных

Структура БД создаётся автоматически через Entity Framework Core. Для ручного развёртывания
можно использовать `Database\rospiv_schema.sql` — скрипт создаёт только структуру.
Для наполнения демонстрационными данными используйте `Database\test_data.sql`.
Учётная запись администратора создаётся приложением при первом запуске.

Основные таблицы: `Users`, `Products`, `Resources`, `Product_recipes`, `Warehouses`,
`Warehouse_stocks`, `Stores`, `Store_warehouse_distances`, `Investment_companies`,
`Investment_rates`.

## Отчёты и служебные каталоги

- `Reports` — сформированные HTML-отчёты.
- `Logs` — журнал необработанных ошибок.
- `images` — изображения товаров.
- `Assets` — логотип, иконка и заглушка изображения.

Все каталоги создаются автоматически при запуске.
